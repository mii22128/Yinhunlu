# 《升天图》第一版初步方案

> 基于马王堆一号汉墓 T 形帛画的二维国风知识科普互动小游戏。  
> 已确认：文物对象为该幅 T 形帛画；每分区一景、横向展卷；第一版只跑通升天主线。  
> 本文为需求方案，确认前不进入开发。

---

## 一、游戏定位

**《升天图》** 是一款对着 **马王堆一号汉墓 T 形帛画** 做的二维叙事探索小游戏。

玩家不是在旁边看说明牌，而是以亡魂进画：按原画分区走人间、双龙、神异、天门、天界，用探索和选择读汉代的生死观、升仙和宇宙秩序。

第一版是 **3–5 分钟可玩完的展示原型**：讲清「如何把一幅静态帛画变成可走的文化叙事」，不做成大系统。

现有工程只留骨架（切场、点击、分支、知识卡）。书院 / 桃源 / 龙门那条故事和素材整段换掉。

---

## 二、核心体验

1. **读画即游戏**：每关是原画上的一个分区，左右展开像打开长卷。
2. **点画中物，不点 UI 按钮**：神兽、祭器、门阙出知识碎片；关末用画面上的路（龙头 / 龙尾、幡帛、仙使）分路。
3. **知识藏在旅程里**：当场以竹简弹出；只有真正交互过的条目，才写入文化图鉴。
4. **文化图鉴可回看**：首页、局内、结束后都能打开图鉴，复习已走过的画区与知识点。
5. **选择是理解，不是对错**：第一版分路改变带路者和知识侧重，不锁死结局。
6. **最终反转**：天界问「你真的进了天界吗？」镜头拉远，整幅 T 形出现——走的是古人画好的升天之路。

---

## 三、基本流程（第一版）

```
首页（展卷 / 文化图鉴入口）
 → 亡魂苏醒（短序，可并入人间）
 → 人间祭祀（横卷）
 → 幡帛引路
 → 双龙之路（横卷）── 近龙尾 → 地下短景 → 引回
 → 顺龙 / 引回后 → 神异（句芒）
 → 仙使或神鸟带路
 → 天门
 → 礼仪入天界
 → 天界展开 → 反转对照整幅
 → 结束（可打开图鉴，或回首页再看图鉴）
```

关与关之间，只用 **当前区 + 下一区都说得通** 的元素交接（幡帛、双龙、仙使、帝阍），不用现代「下一关」按钮。

## 四、第一版内容

| 关 | 对应原画 | 可点 | 关末一问 | 带去下一关 |
| --- | --- | --- | --- | --- |
| 序 / 人间 | 中段：墓主、宴祭、鼎壶、乐悬 | 祭品、乐、幡帛 | 跟随幡帛（「留在人间」整段结局不做） | 幡帛 |
| 双龙 | 中段：双龙穿璧 | 龙身、谷纹璧 | **顺龙前进** / **靠近龙尾** | 顺龙：沿龙身上行；龙尾：入地下短景后再被引回 |
| 地下（短） | 下段：鲸鲵、力士等 | 1–2 个点 | 无第二条长线 | 力士 / 龙身托回神异 |
| 神异 | 中上：人面鸟等 | 句芒（人面鸟） | **倾听** / **攻击**（只改知识与生命感，不加新地图） | 神鸟或仙使 |
| 天门 | 上段门阙：帝阍、守卫 | 门阙、使者、飞廉 | 行礼通过 | 帝阍开门 |
| 天界 + 反转 | 上段横幅：日月、蟾蜍、玉兔、扶桑 | 2–3 个点 | 天神一问，拉远整幅 | 结束 |

### 选择（至少 3 次）

1. 人间：点齐关键物后随幡帛离开（探索本身算交互，不作第二结局）。
2. 双龙：龙头主线 / 龙尾地下短景。
3. 神异：倾听或攻击。

### 知识（第一版约 8–10 条）

幡帛引魂、祭祀饮食、礼乐、双龙穿璧、（若走龙尾）地下鲸鲵或力士、句芒 / 人面鸟与生命、帝阍与天界秩序、日乌扶桑、月蟾玉兔。每条带原画位置。有争议的定名（如人面鸟是否即句芒）用一句「一说」带过，不写成定论。

### 界面

- **首页**：展卷开始；另有「文化图鉴」入口（印章 / 册页），未收录时也可点开，见空册说明。
- **关卡内**：主区可横拖；下方为旁白卷轴；角上用册印进入图鉴，并显示已收条数。不要血条、等级、现代关卡条。
- **结束后**：可再开图鉴，或回到首页从入口回看。

## 五、文化图鉴

局内名称可用《升天录》。玩家在关卡里点过、听过、选过的知识点，才会被收录；不是开局就摊开全部词条。

### 收录规则

- **收录时机**：该条对应的画面交互完成（点到祭器 / 神兽 / 门阙，或完成与该条绑定的关末选择）并关闭当场竹简之后，写入图鉴。
- **未交互**：不收录。未走过的关、没点到的物，图鉴里保持「墨迹未干」或空位，不剧透正文。
- **分路差异**：只走龙头则不收地下专属条；近龙尾并点过地下物，才收鲸鲵 / 力士等。倾听或攻击可共用句芒条，用一句附记区分侧重（生命循环 / 人与自然）。
- **可回看**：收录后可在首页、局内、结束页反复打开，不中断已收集进度（第一版用本地保存即可）。

### 词条结构（每条）

```
——————
名称（如：句芒鸟）
原画位置（如：中上 · 人面鸟）
象征 / 身份（如：一说东方春神，生命循环）
简述（当场弹出的知识正文，略可加一句对照）
——————
```

### 图鉴界面

- 形式：古籍册页 / 竹简层叠，按画区分栏（人间、双龙、地下、神异、天门、天界）。
- 已收：可点开复读完整竹简。
- 未收：只显示分区名或剪影，不出现关键解释。
- 册首：已收数 / 本趟可收数（可收数随是否走进地下短景变化）。

### 入口位置（第一版必须有）

| 位置 | 作用 |
| --- | --- |
| 首页 | 主入口之一，与「展卷」并列可点；方便通关后回来复习 |
| 关卡内 | 角上册印，随时回看已收条，不强制 |
| 结束页 | 反转之后提供「观图鉴」；也可回首页再进 |

## 七、素材需求（第一版）

### 必须有

可用帛画风插画或精细 SVG 先顶上，构图要能对上原画分区。

- **场景**：展卷、人间祭祀、双龙、地下短景、神异、天门、天界；结局一张 **T 形全图对照**（示意即可）
- **角色**：亡魂、双龙、人面鸟、帝阍 / 使者；地下短景要力士或鲸鲵（至少一个）
- **UI**：宣纸底、云纹边、印章、竹简知识卡、文化图鉴册页（首页入口、局内册印、空册 / 已收态）
- **转场**：幡帛、墨迹 / 卷轴展开（CSS 或简单 SVG 即可）

### 第一版不做

正式配乐音效包、原大高清原件贴图。

可继续用现在的 `index.html` + `css/` + `js/game.js|scene.js|data.js`，内容整换；横卷和「点画面、不点按钮」要在场景层补，不另起项目。图鉴数据与关卡知识点共用同一份内容模块。

## 八、完成标准（第一版可验收）

玩家能在约 **3–5 分钟** 内：

1. 展卷，进入亡魂视角
2. 在 **不少于 4 个分区**（人间、双龙、神异、天门、天界；地下短景可选）里横卷探索并点到物
3. 做完 **至少 3 次** 选择（含双龙分路、神异倾听 / 攻击）
4. 当场打开竹简知识卡；交互过的条目写入文化图鉴，未点过的不出现正文
5. 首页、局内、结束页都能进入图鉴，回看已收条目和对应画区
6. 走到天界反转，看见整幅 T 形，读到「旅程即画中升天之路」
7. 画面统一为帛画 / 古籍风，切场是卷轴或幡帛，不是现代淡入按钮

不验收：第二条长线、音效完备、原画像素级还原、学术无争议表述、图鉴跳转回原画热点。
