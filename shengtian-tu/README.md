# 升天图 · 第三版

对着马王堆一号汉墓 T 形帛画做的二维互动绘本。玩家以亡魂进画，走人间、双龙、句芒、天门，经使者引荐后见到人身龙尾的天神。

技术：纯静态 **HTML / CSS / JavaScript**，无构建、无后端。可直接双击打开，也可挂到 GitHub Pages 做成可分享链接。

仓库：https://github.com/mii22128/Yinhunlu  
可分享链接：https://mii22128.github.io/Yinhunlu/shengtian-tu/  
下载页：仓库根目录 [`download.html`](../download.html)，压缩包 [`Yinhunlu.zip`](../Yinhunlu.zip)。

## 本地打开

把压缩包完整解压后，打开 `shengtian-tu` 文件夹里的 `index.html`。不要在未解压的压缩包窗口里直接双击。

```bash
cd shengtian-tu
python3 -m http.server 43172 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:43172`。调试跳关：`http://127.0.0.1:43172/?debug=1`

## 手机

- 请**横屏**游玩。竖屏会全屏提示「请将手机横过来」。
- 横屏后铺满视口；知识卡从底部弹出。
- 旋转、改窗口大小会自动在手机 / 平板 / 电脑界面之间切换。

## 怎么玩（主线摘要）

1. **人间**：点击宴乐人物与案上酒食。点齐后知识卡，幡帛分路。留恋人间 → 结局「无名游魂」。跟幡 → 双龙。
2. **双龙**：回头 → 玄武衔芝。不吃 → 「有病不吃药的来」。吃下 → 力士 → 「永堕深渊」。向前 → 句芒。
3. **句芒鸟**：听 → 天门。掐死 → 「不敬生灵」，回卷首。
4. **双龙天门**：点辛追夫人看知识卡；左边发光使者分路。献簪后请引荐 → 天界全景 → 天神。自行说明 → 「没被邀」。
5. **天界 / 天神**：先见日月应龙的天界世界，再入云雾见人身龙尾的天神。发问之后，旅途拼贴、水墨散去，T 形帛画现形。

宽度小于 768px 或横着的矮屏走手机界面；768px–1200px 为平板，更宽为电脑。
